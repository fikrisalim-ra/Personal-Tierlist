Kenapa bikin sendiri

Ada banyak tempat bikin tierlist. Ini versi yang kubuat supaya pas dengan caraku mengisinya.

Seret langsung

Banyak gambar sekaligus dari komputer, langsung jatuh ke tier. Tanpa langkah "pilih gambar".

Salah? Gampang dibenerin

Hapus gambar dengan satu klik, dan ada undo kalau kepencet.

Boleh panjang banget

Ratusan tier pun aman. Tier bisa dilipat, dicari, dan inventaris gambar menempel di bawah layar.

Catatan per gambar

Tiap gambar bisa diberi properti sendiri, muncul saat di-hover seperti info item di game.

Banyak tierlist

Satu untuk karakter, satu untuk game, satu untuk makanan. Semuanya terpisah dan rapi.

Dibawa kemana-mana

Export jadi PNG untuk dipamerkan, atau file JSON sebagai cadangan yang bisa dibuka lagi.

FAQ

Pertanyaan yang paling sering muncul. Mau nambah? Salin satu blok <details> di bawah, lalu ganti teksnya.

Apa bedanya dengan Tiermaker?

Aku bikin ini karena di tempat lain aku harus memilih gambar satu per satu dan susah menghapus gambar yang salah. Di sini gambar diseret langsung dari komputer, bisa dihapus dan di-undo dengan mudah, dan tiap gambar bisa punya catatan sendiri. Ini juga lebih personal: tierlist milikku, tersimpan di browserku.

Apakah perlu membuat akun?

Tidak. Tidak ada daftar, tidak ada login. Buka, lalu langsung pakai.

Di mana data saya disimpan? Apakah ada yang bisa melihat gambar saya?

Semuanya tersimpan di browser kamu sendiri, di perangkat yang kamu pakai. Gambar dan tierlist tidak dikirim ke server mana pun. Situs ini di-host di GitHub Pages, jadi GitHub bisa mencatat kunjungan ke halaman seperti situs web lain pada umumnya, tapi isi tierlist-mu tidak pernah sampai ke sana.

Bagaimana kalau saya membersihkan data browser atau ganti perangkat?

Tierlist-nya ikut hilang, karena datanya memang hanya ada di browser itu. Karena itu ada tombol Export dan pengingat backup di bagian atas. Biasakan export setelah selesai mengedit, dan simpan filenya di tempat lain.

Bagaimana memindahkan tierlist ke perangkat lain?

Klik Export di perangkat lama untuk mendapatkan file JSON, lalu klik Import di perangkat baru dan pilih file itu. Hasil import selalu menjadi tierlist baru, jadi tidak akan menimpa yang sudah ada.

Apakah gratis?

Gratis. Tidak ada iklan dan tidak ada pelacak dari sisiku.

Berapa banyak gambar dan tier yang bisa dipakai?

Aplikasinya sendiri tidak membatasi. Batasnya ada di ruang penyimpanan browser-mu. Gambar biasa dikecilkan otomatis (sisi terpanjang 400 px) supaya hemat tempat, dan saat export PNG, tierlist yang panjang dipecah jadi beberapa file.

Apakah gambar GIF didukung?

Didukung dan tetap bergerak di tierlist. GIF tidak dikecilkan, jadi ukurannya bisa besar. Saat export PNG, GIF menjadi gambar diam.
